    주문한 가게 실시간 조리 타이머

      1. 웹 접근성 체크리스트 점검표

      영역 점검 항목 결과 확인 방법 및 적용 내용
      1. 이미지 대체 텍스트 의미 있는 이미지 alt / 아이콘 버튼 aria-label 충족 25개 음식 SVG 일러스트 및 사용자 등록 이미지에 alt·aria-label 제공, 상단·색상 버튼에 aria-label 명시
      2. 키보드 접근성 Tab 이동, :focus-visible 유지, 본문 바로가기 충족 outline: none 제거 후 :focus-visible 스타일 적용 및 상단 스킵 링크 제공
      3. 색상 및 대비 명도 대비 4.5:1 이상 및 텍스트 병행 안내 충족 청록 버튼(#0d9488)과 진한 텍스트(#111827)로 4.5:1 이상 확보, 최소주문금액 상태를 색상+텍스트로 함께 표시
      4. 폼 접근성 label 연결, required 필수 표시, role="alert" 오류 안내 충족 배달 주소·수령 방식·커스텀 메뉴 등록 폼에 label for, required, aria-describedby 및 오류 메시지 연결
      5. 구조와 의미 제목 계층(h1~h3), 시맨틱 태그, 표 th[scope] 충족 header, nav, main, aside, footer 구조화 및 장바구니 표 <th scope="col"> 사용
      6. 미디어 자막(CC) 제공, 재생/정지 제어, 깜빡임 예방 충족 가이드 자막(CC) 영역과 재생·일시정지·정지 버튼 구현, prefers-reduced-motion 반영
      6. 미디어 (영상) 동영상 파일 직접 삽입 항목 해당 없음 실시간 🛵 오토바이 벡터 지도와 자막 가이드를 사용하여 별도 동영상 파일은 포함하지 않음

      3. 주요 기능별 코드 및 설명

      ① 기능명: 직접 그린 캔버스 일러스트 메뉴 등록 (registerCustomIllustMenu)

      function registerCustomIllustMenu(store, name, price, desc) {
  const dataUrl = illustCanvas.toDataURL("image/png");
  ALL_MENUS.unshift({
    id: Date.now(),
    store,
    name,
    desc: desc || "직접 그린 일러스트 스페셜 메뉴 · 준비 10분",
    prep: 10,
    options: [{ label: "기본 구성", price }],
    customImg: dataUrl
  });
  renderMenuList();
}
      • 함수의 역할: 사용자가 캔버스에 그린 일러스트 그림을 PNG 데이터 URL로 변환해 새 메뉴 카드로 추가하는 함수입니다.
      • 호출 시점: [그림·일러스트 그리기] 화면에서 [그림 일러스트 메뉴 등록하고 보러가기] 폼을 제출할 때 호출됩니다.
      • 처리 과정: canvas.toDataURL("image/png")로 그림 이미지 추출 → 가게명·메뉴명·가격과 함께 ALL_MENUS 배열 맨 앞에 추가 → renderMenuList()로 화면 갱신.
      • 실행 결과: 방금 그린 그림이 alt 속성이 포함된 메뉴 카드로 즉시 표시되어 장바구니에 담고 주문할 수 있습니다.
